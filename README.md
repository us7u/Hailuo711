# فيديو مطاردة سينمائي وسط الثلج

تم إنشاء فيديو رسوم متحركة سينمائي بالكامل بطريقة إجرائية، من دون استخدام صور ثابتة أو صور مولّدة أو لقطات جاهزة.

## الفيديو النهائي

- الملف: `cinematic-snow-survival.avi`
- المدة: 12 ثانية
- الدقة: 960×540
- معدل الإطارات: 24 إطاراً/ثانية
- الفيديو: Motion JPEG
- الصوت: مؤثرات PCM مولّدة برمجياً
- المحتوى: رجل يركض وسط عاصفة ثلجية، يطارده دب وحشي ويعض معطفه، ثم يدافع الرجل عن نفسه بفأس. المشهد غير دموي.

## إعادة إنشاء الفيديو

يتطلب Python 3 وImageMagick (`convert`):

```bash
python3 make_video.py -o cinematic-snow-survival.avi --quality 82
```

يرسم `make_video.py` كل إطار كرسوم متجهة متحركة ويولّد مؤثرات الرياح والخطوات والزئير والضربة برمجياً، ثم يضمّها في ملف AVI واحد.
